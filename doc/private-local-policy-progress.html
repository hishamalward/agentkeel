Release progress · AgentKeel 0.12.0 · 19 October 2026

No policy in the public repository.

AgentKeel activation now belongs to the machine that enabled it. Repository policy is stored in private Git metadata and shared only among local linked worktrees.

Activatetask.py init registers the Git common directory under AGENTKEEL_HOME.
Configuretask.py init --policy FILE validates and copies a JSON object to the Git common directory.
Removetask.py deactivate deletes the local registration and private policy without touching repository files.

Changed behavior

  • A public agentkeel.json no longer activates plugin hooks.
  • init no longer creates policy or instruction files in the worktree.
  • Linked worktrees resolve one policy through their shared Git common directory.
  • Independent task clones receive a private policy and registration, then remove both on release.
  • The obsolete managed AGENTS.md fragment and implementation were removed.

Python compilation and diff checks pass. All 319 tests pass, including activation, deactivation, linked-worktree policy sharing, isolated-clone cleanup, shipping, guard behavior, documentation links, and the repository contract.
